# Контрольная точка восстановления (Checkpoint v1)
Дата создания: 2026-10-01
Версия: Базовая полнофункциональная версия с ручным прицелом, рывком, хедшотами, разрушаемыми укрытиями, 3 режимами и процедурным Web Audio звуком.

Все исходные файлы зафиксированы в этой точке перед внедрением расширенных визуальных эффектов (Aurora Borealis, луна со звездами, искрящийся снег, следы на снегу, пар от дыхания, улучшенные взрывы снежков и ледяные узоры на экране).
